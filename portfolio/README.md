# SalesPulse portfolio assets

Reusable material for presenting the project without overstating what it is.

| File | Use |
|---|---|
| [case_study.md](case_study.md) | Full case study: problem, build, decisions, results, limitations |
| [demo_script.md](demo_script.md) | Three-minute walkthrough, a 90-second version, and likely Q&A |
| [resume_bullets.md](resume_bullets.md) | Résumé bullets, compact project entry, LinkedIn blurb |

All data in SalesPulse is synthetic. The demo script includes a “do-not-claim” list to keep
presentations accurate.

Start with the [root README](../README.md), then the
[screenshot gallery](../docs/screenshots/README.md) and [sample report](../docs/sample_report.md).
